## 2. Tipografia / Tipografía / Typography
| Tipo / Type | Família / Family | Uso / Use |
|--------------|------------------|-----------|
| **Título / Title** | Montserrat Bold | Cabeçalhos e seções principais |
| **Texto / Body** | Open Sans Regular | Parágrafos e descrições |

---

## 3. Ícones / Iconografía / Icons
- **Estilo:** Linear, minimalista, com traços uniformes.
- **Tamanho padrão:** 24px para interface, 48px para documentação.
- **Conjunto base:** Material Symbols + ícones personalizados da AI-Commerce Platform.
- **Uso:**
  - 🧠 Inteligência Artificial
  - 💬 Comunicação
  - ⚙️ Operações
  - 🌐 Globalização
  - 🔒 Segurança

---

## 4. Logotipo / Logotipo / Logo
- **Versão principal:** Cabeça de robô azul com antena e ícones de comércio e conectividade.
- **Versão reduzida:** Apenas o robô com fundo transparente.
- **Margem de segurança:** 20px em torno do logotipo.
- **Proporção mínima:** 120px de largura.
- **Uso incorreto:** Não alterar cores, proporções ou adicionar sombras.

---

## 5. Aplicações / Aplicaciones / Applications
- **Documentação:** Capa corporativa e cabeçalhos de seção.
- **Apresentações:** Slides iniciais e finais.
- **Interfaces:** Cabeçalho, rodapé e ícones de navegação.
- **Marketing:** Materiais digitais e impressos com fundo azul primário.

---

## 6. Diretrizes de Consistência / Guidelines / Directrices
- Manter contraste adequado entre texto e fundo.
- Usar espaçamento uniforme (24px entre seções).
- Seguir o padrão trilíngue (PT/ES/EN) em todos os materiais oficiais.
- Garantir que todos os elementos visuais reflitam inovação, clareza e confiança.
